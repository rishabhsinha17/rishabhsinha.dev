# Rishabh Sinha — portfolio

A dependency-free, single-page portfolio focused on ML systems, distributed infrastructure, research, and open-source work.

## Preview

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

The page intentionally uses system fonts and no third-party JavaScript. It supports dark mode, keyboard navigation, reduced motion, mobile layouts, semantic landmarks, and print-friendly output.

The personal phone number is intentionally not published. Research entries link to public code and project artifacts; add exact arXiv abstract URLs once identifiers are available.
